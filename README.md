# Connect - Real Time Chat App 🌍

A real-time chat application that connects people from anywhere in the world. Built with Firebase and vanilla JavaScript.

## Features
- 🔐 Email/Password Authentication
- 💬 Real-time messaging
- 👥 Online users tracking
- 📱 Mobile responsive
- 🌐 Works on any device

## Live Demo
[Click here to chat!](https://hoxexo.github.io/connect-chat-app)

## How to Use
1. Sign up with your email
2. Start chatting with online users
3. Messages appear in real-time

## Technologies Used
- Firebase Authentication
- Cloud Firestore
- HTML5/CSS3
- JavaScript

## Setup
1. Clone this repository
2. Open `index.html` in your browser
3. Sign up and start chatting!
